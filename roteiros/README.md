# Roteiros WAS (construtor de roteiros)

Arquivos do construtor de roteiros usado na página de teste `/mundo-was/roteiros` do site da World Adventure Society.

- `v1/roteiros-dados.js`: lugares e rotas do Mapa da aventura (gerado a partir dos JSON do mapa).
- `v1/roteiros.js`: o aplicativo (roda no navegador, guarda os roteiros no navegador de quem usa).
- `v1/roteiros.css`: estilos, todos dentro de `#wasrot`.

O site carrega os arquivos pelo jsDelivr, fixados num commit.
